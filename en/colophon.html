About the Project

Who made this website, what it is based on, and how it is built.

An independent educational project

This website is a student project created by Askarova Zeinep for an introductory web technologies course. It is built around a real cultural institution — the Military-Historical Museum in Astana — and is not the museum’s official website.

The text draws on the public sources listed on this page. Where they disagree — opening hours, ticket prices, the number of objects, the number of halls — the differences are shown openly instead of being hidden.

The Russian and Kazakh versions are translations of the English text; the Kazakh and Russian names of the museum are those shown on its entrance banner.

How it is built

  • Semantic HTML5: header, nav, main, section, article, aside, figure, table, form and footer.
  • Assignment 2 adds ordinary external CSS: shared base.css plus Zeinep's personal stylesheet. It uses no framework, responsive media queries or JavaScript.
  • Three language versions live in the folders en/, ru/ and kk/; every page links to its twin in the other two languages.
  • Photographs are compressed JPEGs with descriptive file names and alternative text in each language.

Project structure

en/  ru/  kk/  (same 17 HTML pages per language)
images/  (32 photographs)
images/thumbs/  (32 thumbnail JPEGs)
css/  zeinep-bootstrap.css  (Bootstrap 5.3.8 CDN)
